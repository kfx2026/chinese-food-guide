# Chinese Food Guide 🥢

A visual guide to authentic Chinese cuisine, organized by province. Explore the bold flavors of Sichuan, Cantonese dim sum, Beijing roast duck, and more.

**🌐 Live Site:** [https://kfx2026.github.io/chinese-food-guide/](https://kfx2026.github.io/chinese-food-guide/)

## Features

- **By Province** — Discover dishes from Sichuan, Guangdong, Beijing, Shanghai, Hunan, and more
- **English & Chinese** — Bilingual content for international food lovers
- **Cooking Methods** — Step-by-step recipes for each dish
- **Food Images** — Mouth-watering photos for every dish
- **Challenge Foods** — Dare to try Sichuan's boldest: rabbit head, grilled brain flower, pork intestine
